Filmarr Android — Ratio Spec
Engineer-facing build companion to Filmarr Android.dc.html · Jetpack Compose (Material 3, dark)
§0 · How to read this spec
Every dimension is classified as one of three kinds. Implement each by its kind — do not eyeball pixels off the mockup.
KindRule
(a) DensityType, radius, stroke, icon size, elevation, padding, gaps, fixed row/chip/bar heights. Fixed dp/sp token, never scaled by width. When unsure → density.
(b) Width-classScreen edge margin, card width, primary button, avatar, FAB, hero art. % of screen width with clamp(min, %, max). Short whitelist — see §1.6.
(c) VerticalWhere blocks sit down the screen. Ordered Column of fixed/intrinsic-height blocks + exactly one Modifier.weight(1f) spacer. Never a coordinate table.
Baseline reference size: 411 × 891 dp (Pixel 8, density 2.625, the mockup's frame). Every % in §1.6 is computed against 411 dp width. All dp/sp values are final on any density.
Division of labor: this doc is the frontend engineer's complete intent — every element's purpose and behavior is stated (see the ⚙ rows in §2, the flows in §3, and the full navigation map in §5). The implementing agent owns everything behind it: data fetching (TMDB), persistence, auth, sync, the recommender, and AI calls. If a behavior is ambiguous, §5 wins; if a dimension is ambiguous, §1 wins.

§2.6 · Quick-add radial (signature)
PropertyValue
TriggerLong-press 280ms on any §2.5 row → scrim rgba(0,0,0,.55)+blur, row lifts scale 1.04
ActionsStacked (9dp): Mark watched (green, primary, "release ↑") · Add to watchlist (card) · rate row (5 stars, "slide to rate — optional")

⚙ PurposeThe signature backlog-clearing gesture: log in one continuous press without opening anything. A "When?" link in the sheet opens the Confidence-log sheet (§3) for films seen long ago.

§3 · Screen recipes
Each screen is a vertical Column under status bar §2.2 + above nav §2.1. Exactly one ◆ weighted spacer per screen absorbs slack.
Onboarding · taste
display headline → body sub (12dp) → chip wrap (genre chips §2.7, gap sm, 22dp top) → ◆ spacer → progress §2.8 + "5/5" → primary CTA §2.7 "Build my deck" → "Skip — surprise me" (meta, centered, 14dp)
Discover · live
header §2.3 ("Discover" + "Swipe to curate" + 2 action circles) → deck §2.4 filling ◆ the flex region (inset 18dp x / 108dp top / 74dp bottom) → undo FAB (50dp, bottom-right, over deck) → nav §2.1. Focus variant: add review panel over lower card (stars + note field), toggled by focus action.
Build
header §2.3 + progress §2.8 ("142 logged") → vertical edge labels (← NOT SEEN · SEEN →) beside → single card §2.4 w/ "Likely seen" pill filling ◆ → nav §2.1
Film detail
backdrop §1.6 (72% width, bottom fade to bg) w/ back circle → ◆ scroll body: display title → meta row → rating row (TMDB numeral + your-stars) → action row (Watched §2.7 + ♥ + bookmark icon buttons) → synopsis body → "CAST" eyebrow + avatar row (46dp circles + "+9") → nav §2.1
Library · Grid / Diary / Lists
header §2.3 ("Library" + count) → segmented §2.7 → ◆ scroll area. Grid: 3-col §1.6, 2:3 posters rsm, ★rating badge bottom-left. Diary diff: month eyebrow + entries = date col (30dp) + 38×54 poster + title/stars/review. → nav §2.1
Search + Quick-add · signature · opened via center FAB
header §2.3 + search field (46dp, card+hairline, leading magnifier) → ◆ results: "RESULTS" eyebrow + §2.5 rows, then "Because you searched" graph-match group → nav §2.1. Quick-add overlay: §2.6 radial on long-press.
Backlog Blitz · catch-up
header row (title+sub · "LOGGED TODAY" green counter) + search field → ◆ grid: "Popular you likely saw" eyebrow + 2-col §1.6 landscape tiles (16:10), tapped=dim+green ✓ badge top-right → snackbar §2.9 (above nav) → nav §2.1. Header carries the streak chip (flame + "6-day streak", rose @15% pill): streaks count consecutive days with ≥1 log — gamify the logging, not the watching. Tile behavior: tap = instant watched log (toggle) · long-press = Confidence-log sheet for fuzzy dating.
Tonight · long-press the FAB
Ambient dot-grid background (§1.2) → display headline "What's the mood tonight?" → "MOOD" eyebrow + single-select chips (Cozy · Tense · Weird · Big & loud) → "TIME YOU'VE GOT" slider (60–240min, thumb 18dp) → "WATCHING WITH" segmented (Solo · Date · Group) → ◆ spacer → the pick: one §2.4-style card (150dp, "YOUR PICK" pill, match %) → action row: Watch this (marks watching + opens detail) · Reroll (crossfades in the next-best match, never repeats a session's rejects) → nav §2.1. Purpose: kill scroll paralysis — the engine returns exactly one answer, filtered to runtime ≤ time slider, ranked by mood-tag match against the taste graph.
Confidence log · fuzzy memories are valid data
Bottom sheet (§1.5 r24 top, surface #141519, drag handle 36×4dp) over dimmed parent → film identity row (46×66 poster + title/meta) → "WHEN DID YOU SEE IT?" chips (This year · A few years back · 2010s · Long ago · No idea — single-select, blue) → "HOW DO YOU REMEMBER IT?" 4-up sentiment tiles (Loved · Liked · Meh · Nope — Bricolage 15, selected = green @14% fill) → AI note (rose @8% pill): "Fuzzy is fine. filmarr refines dates & ratings later as your taste graph grows." → CTA "Log it — fuzzy and all". Purpose: Letterboxd forces precision; real memories aren't precise. Entries store a date-range + sentiment instead of date + stars; the AI layer may later propose refinements the user confirms. Opened from: Blitz tile long-press, quick-add "When?" link, Build card long-press.
Overlap · taste graph as a social object
Ambient dot-grid background → identity row (two overlapping 34dp avatars, −10dp offset + "You × Ana" + "Taste overlap · 68%") → ◆ venn canvas: two 88r circles (yours rose @13%, theirs blue @13%, stroked @50%), solo nodes in each lobe, shared films in the intersection, labels YOURS / ANA'S / THE OVERLAP → "IN THE OVERLAP — NEITHER OF YOU HAS SEEN" eyebrow + reco row (both-match % + Watch together button) → nav §2.1. Purpose: the overlap zone IS the recommendation — films both graphs point at that neither has logged. "Watch together" adds to both watchlists and notifies the friend. Node tap → Film detail. Reached from Profile → friends list, or a shared graph link.
Ask filmarr · AI
rose-glyph title row → ◆ conversation §2.10: user bubble → AI answer → result card (add ✓) → "TRY ASKING" eyebrow + 3 suggestion chips → input bar §2.10 (bottom 12dp). No bottom nav (modal-style surface).
Profile · stats
identity row (avatar §1.6 + name/@handle + settings gear) → 3 stat cards (surface.raised, stat-numeral) → "RATINGS SPREAD" histogram (6 bars, gold/rose peaks) → "TOP GENRES" bars → ◆ spacer → nav §2.1
Letterboxd import
back circle → centered hero (3-dot LBXD mark + title + body) → progress card §2.8 (862/1204 + matched/review/queued stats) → "ALSO SYNC" eyebrow + 3 toggle rows §2.7 → ◆ spacer. No nav (settings sub-page).
Taste graph
title block ("Your taste graph" + sub) → ◆ graph canvas: central YOU node (22dp gradient) + 5 satellite nodes (12–16dp) with color-coded edges @40% + cluster labels → reco strip §2.5-style (92% match + add ＋) → nav §2.1
