# History

Repositories folded into this one. Each keeps its full commit history under
`history/<name>/`. To read those commits, find the "Fold <name>" commit and run
`git log <that commit>^2`. The original repository is archived on GitHub, never deleted.

- **filmarr-android** (2026-06-16 to 2026-10-18) — filmarr android: `history/filmarr-android/`, original at https://github.com/mehdiacho/filmarr-android (archived).
